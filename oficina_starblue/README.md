# Oficina 3D — actividad del equipo

La pestaña **GitHub** lee la API pública del repositorio `johniadeveloper007/Star-blue` y muestra el último commit de hasta ocho ramas (prioriza `main`, `database/perseo` y `oficina/oficina-3d`) junto con los pull requests abiertos. Se actualiza al cargar, manualmente con **↻**, y cada 15 minutos.
